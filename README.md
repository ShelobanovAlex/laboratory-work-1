Тема лабораторной работы 1: Модель лесного пожара.
1. Изучить принципы построения и работы клеточных автоматов.
2. Разработать клеточный автомат для модели лесного пожара.
3. Определить состояния клеток: пустая клетка, дерево, горящее дерево.
4. Реализовать правила переходов между состояниями:
 а) возгорание дерева при наличии заданного числа горящих соседей;
 б) случайное возгорание от молнии;
 в) выгорание горящего дерева;
 г) рост нового дерева на пустой клетке.
5. Задать и обосновать параметры модели: вероятность роста, вероятность молнии, порог возгорания, начальная плотность леса, тип окрестности.
6. Провести вычислительные эксперименты и собрать статистику по тактам.
7. Построить графики динамики числа деревьев, очагов огня и пустых клеток.
8. Визуализировать процесс распространения пожара и финальное состояние поля.
9. Проанализировать влияние параметров на поведение системы.
10. Сформулировать выводы по результатам моделирования.
